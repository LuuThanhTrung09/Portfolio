03 / Back-end

GAME ACCOUNT MANAGEMENT SYSTEM — ASP.NET Core Web API

ASP.NET Core Web API · Entity Framework Core · SQL Server

Hệ thống backend cho một game quản lý tài khoản & nhân vật người chơi. Xây dựng theo kiến trúc phân lớp Controller – Service – DbContext, cung cấp REST API cho client (Unity) và một Admin Panel (MVC + Razor Views) riêng để quản trị dữ liệu qua trình duyệt.

C# / .NET ASP.NET Core Web API Entity Framework Core SQL Server MVC + Razor MailKit HMACSHA512
Xem code trên GitHub Xem hình ảnh dự án
Architecture

Cách hệ thống được tổ chức

01

Kiến trúc phân lớp

Controller chỉ nhận request và trả response chuẩn hoá qua ResponseApi. Toàn bộ logic nghiệp vụ và truy vấn nằm ở Service, giao tiếp DB qua AppDbContext (EF Core).

  • AccountsController / CharacterController
  • IAccountServices / ICharacterServices
  • AppDbContext : DbContext
02

Bảo mật & xác thực

Mật khẩu không lưu plaintext — băm bằng HMACSHA512 với salt riêng cho từng tài khoản, xác minh lại khi đăng nhập.

  • PasswordHasher (hash + salt)
  • Đăng ký gửi email xác nhận qua MailKit
  • Template email HTML riêng
03

Admin Panel (MVC)

Ngoài REST API cho client, hệ thống có một trang quản trị dựng bằng MVC + Razor View để xem và quản lý tài khoản, nhân vật trực tiếp trên trình duyệt.

  • Đăng nhập / Đăng ký admin
  • Danh sách Account & Character
  • Giao diện tách riêng khỏi API layer

API Reference

Một số endpoint tiêu biểu

Method Route Mô tả
POST /api/register Đăng ký tài khoản mới, gửi email xác nhận
POST /api/login Đăng nhập, xác thực mật khẩu đã băm
PUT /api/change-password Đổi mật khẩu theo Account Id
DELETE /api/accounts/{id} Xoá tài khoản theo Id
GET /api/get-all-charaters Lấy toàn bộ danh sách nhân vật
POST /api/create-new-character Tạo nhân vật mới cho một tài khoản
PUT /api/update-character-by-id Cập nhật tên, level, exp của nhân vật
